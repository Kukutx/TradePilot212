# 国际化

简体中文 · [English](../I18N.md)

TradePilot 目前提供：

- `en` — 英文
- `zh-CN` — 简体中文

<a id="runtime-behavior"></a>
## 运行时行为

1. 如果用户手动选择过语言，并且本地存储可用，组件会保留这个选择。
2. 否则组件跟随 ChatGPT 宿主的语言设置。
3. 不认识的语言设置回退到英文。
4. 货币、数字和时间戳按当前语言用 `Intl` 格式化。
5. OAuth 授权页先看 `ui_locales`，再看 `Accept-Language`。

<a id="add-a-locale"></a>
## 添加一种语言

1. 在 `src/ui/i18n/en.ts` 旁边新建一个词典文件。
2. 保证每个消息键都与 `MessageKey` 兼容。
3. 在 `src/ui/i18n/index.ts` 中注册这种语言。
4. 扩展 `resolveLocale`，让它识别新的语言家族。
5. 在 `src/core/oauth-page.ts` 中添加 OAuth 页面的文案。
6. 运行 `pnpm check`。

不要在翻译文本里假定布局。界面使用自适应容器、可伸缩的按钮和会自动换行的标签，所以添加文字较长的语言时不需要重新设计应用。

<a id="directionality"></a>
## 文字方向

目前的语言都是从左到右（LTR）。如果以后加入从右到左（RTL）的语言，应在语言注册表中加入方向元数据，并根据它设置 `document.documentElement.dir`，而不是添加零散的 CSS 规则。
