# 自选列表

简体中文 · [English](../WATCHLIST.md)

自选列表跟踪你持有或没持有的标的：每个标的的价格怎么走、处在一年区间的什么位置，以及离你在它上面设的挂单和提醒还有多远。Trading 212 的 Public API 没有自选列表，所以 TradePilot 按账户自己保存一份，存在保存价格提醒和定投计划的同一个存储里。它从不发送给 Trading 212，也不会下任何单。

<a id="adding-and-removing"></a>
## 添加和移除

- **在自选标签页。** 在 **添加标的** 下输入名称、代码或 ISIN；边输入边显示匹配项，完全匹配的 ticker、代码或 ISIN 排在最前，已经在列表里的会注明。
- **在标的页面。** **加自选** 把它加进列表；**★ 已自选** 把它移出。页面会显示它从什么时候起在列表上，以及它的备注。
- **在对话里。** `manage_watchlist` 配合 `action: "add"`、一个 `instrument`（ticker、代码、名称或 ISIN，和下单时一样解析）以及可选的 `note`；`action: "note"` 修改列表上某个标的的备注（空备注即清除），不会新增标的；`action: "remove"` 把它移出。添加已在列表上的标的，会改它的备注。

标的加入时会记下当时的价格（持仓用 Trading 212 的价格，否则用行情源在 3 秒内返回的价格），用来计算此后的涨跌。每个账户最多 50 个标的，每个可以写最多 200 个字符的备注，说明为什么关注它；**写备注** 和 **改备注** 在原处编辑。× 移除一行；Trading 212 已不再列出的标的，也可以按 ticker 移除。

<a id="what-each-row-shows"></a>
## 每一行显示什么

- **现价**：持仓用 Trading 212 的价格，其他用行情源的价格，都没有时用最近一个日收盘价，并注明日期。
- **涨跌**：现价相对前一收盘价的变化（**1日**：价格所属那一天之前的最后一个收盘价，所以周末时周五的报价会和周四比较；持仓的 Trading 212 价格属于所在市场正在进行的或最近一个交易时段，和仪表盘一样），或者在收盘价完整覆盖该时段时，近 1、3 或 12 个月的变化。数字会写出来，不只靠颜色表示。
- **三个月**的收盘价画成一条小线，终点是现价；收在起点之上为绿色，之下为红色，起点处有一条横贯的虚线。
- **12 个月区间**：价格处在一年里最低和最高收盘价（以及现价）之间的什么位置，以及比高点低多少。收盘价不满一年时（新上市，或 Alpha Vantage 只有 100 天），改为给出从收盘价第一天起的区间。
- **价位**：最近的一笔挂单（止损单看触发价，限价单看限价）或已启用的高于/低于价格提醒，以及它离现价多远；还有其他的时显示“另有 2 个”。`get_watchlist` 按从近到远返回全部。
- **加入以来**：从加入时的价格算起的涨跌，满一天后显示。两个价格相差十倍时不显示，因为这说明其中一个用的是另一个单位。
- **你的备注。**

可以按加入顺序、所选时段内涨跌幅最大，或离挂单或提醒最近排序。点一行会打开该标的的页面。

<a id="prices-and-limits"></a>
## 价格和限制

日收盘价来自行情源，和持仓页图表画的是同一份，缓存半小时（[AUTOMATION.md](./AUTOMATION.md#quotes-for-instruments-you-do-not-hold)）。标签页每次同时读取四个标的，5 秒后不再发起新的读取；超出的行会注明，并在下次刷新时取到价格。与 Trading 212 的价格、或与该标的挂单和提醒价格相差十倍及以上的收盘价，会被视为另一个单位而不使用，行情源对它的报价也一并不用；收盘价没取到时，报价同样会和挂单及提醒价格这样比对。这一行会注明能修正它的 `QUOTE_SYMBOLS` 换算系数。没有行情源，或行情源没有该标的的代码时，持有的标的仍显示 Trading 212 的价格，其他标的会说明为什么没有价格。

免费行情套餐每分钟只允许少量请求，并且与价格提醒和持仓页共用，所以在这类套餐上，较长的自选列表要刷新几次才能填满。

<a id="in-the-chat"></a>
## 在对话里

`get_watchlist` 返回上面这些行，并为没有界面组件的宿主附上文字摘要：每个标的的价格及其来源、收盘价覆盖的每个时段的涨跌、区间、价位、持有时的仓位、加入以来的涨跌和备注。两个工具都不需要下单工具。

样例账户（`TRADEPILOT_SAMPLE_DATA=true`）离线用模拟报价和收盘价给自己的标的定价，除了持仓之外，还列出 Amazon 和 ASML 作为观察对象。
