# Internationalization

TradePilot currently ships with:

- `en` — English
- `zh-CN` — Simplified Chinese

## Runtime behavior

1. If the user manually selected a language, the widget keeps that preference when local storage is available.
2. Otherwise the widget follows the ChatGPT host locale.
3. Unknown locales fall back to English.
4. Currency, numbers and timestamps use `Intl` with the active locale.
5. The OAuth authorization page resolves `ui_locales` first, then `Accept-Language`.

## Add a locale

1. Create a dictionary beside `src/ui/i18n/en.ts`.
2. Keep every message key compatible with `MessageKey`.
3. Register the locale in `src/ui/i18n/index.ts`.
4. Extend `resolveLocale` for the new locale family.
5. Add the OAuth page copy in `src/core/oauth-page.ts`.
6. Run `pnpm check`.

Do not put layout assumptions in translated text. The UI uses responsive containers, flexible buttons and wrapping badges so languages with longer labels can be added without redesigning the application.

## Directionality

The current locales are LTR. If an RTL language is added later, extend the locale registry with direction metadata and set `document.documentElement.dir` from that metadata rather than adding one-off CSS rules.
